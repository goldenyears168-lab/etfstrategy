# 相對輪動圖（RRG）入門

> 用高中數學就能讀懂：加權平均（WMA20）、標準化到 100、函數與導數、平面運動。  
> **本專案實作 SSOT**：`src/rrg_rotation.py`（Julius de Kempenaer · TradingView WMA 雙平滑）。

---

## 這張圖在回答什麼？

市場上有很多標的（股票、ETF、產業），我們常想知道：

1. **它現在相對大盤/基準，是強還是弱？**（位置）
2. **這個相對強弱正在變快，還是變慢？**（變化率）

**Relative Rotation Graph（RRG，相對輪動圖）** 把這兩個問題畫在同一張平面上：橫軸看「水準」，縱軸看「斜率」，時間一週一週（本專案為**日頻**）推進，每個標的會留下一條軌跡（尾跡）。

如果你學過：

- **WMA20**（20 期加權移動平均）
- **標準化到 100**（把均衡點對準 100，不是 z-score）
- **微積分**（函數、一階導數、相平面）

那 RRG 其實就是：**把相對強弱這條時間序列，嵌入 (x, dx/dt) 相平面**——位移是 RS-Ratio，速度是 RS-Momentum。

## 第一步：相對強弱 RS（一維位移）

選一個**對照基準**（本專案：`IX0001`），再選一個**標的**（例：某檔成分股）。

定義：

```text
RS(t) = 標的收盤(t) / 基準收盤(t)
```

| 符號 | 意義 |
|------|------|
| `RS > 1` | 標的累積價格水準高於基準（比值意義，非報酬率） |
| `RS = 1` | 與基準同價比 |
| `RS < 1` | 標的累積價格水準低於基準 |

在運動學類比裡，`RS(t)` 是**一維位移**：標的相對基準「走到哪裡了」。

> 注意：`RS` 是**價格比值**，不是日報酬率。報酬率要用 `RS(t) / RS(t-1) - 1`。

## 第二步：WMA 平滑（去雜訊）

日資料有雜訊。JdK 實作不直接拿原始 `RS(t)` 畫軸，而是全程用 **WMA** 低通濾波。

### WMA 公式（與 `rrg_rotation.wma()` 一致）

**Weighted Moving Average（加權移動平均）** 給近期較大權重。以 L 期為例，視窗內由舊到新權重為 1, 2, …, L：

```text
WMA_L(x)_t = Σ(k · x_{t-L+k}) / (L·(L+1)/2)     ，k = 1, 2, …, L
```

L=20 時分母為 210；**今天**（視窗最右）權重 20，**L 日前**權重 1。

先對 RS 做第一層平滑：

```text
RS_bar(t) = WMA_L(RS)_t
```

### 為什麼要平滑？

| 不做平滑 | 做 WMA |
|----------|--------|
| 軌跡鋸齒、難判讀 | 保留大方向、去掉高頻雜訊 |
| 象限來回跳 | 象限轉換更有意義 |

類比物理：**低通濾波**——保留慢變化的趨勢，濾掉快速抖動。

> 前 L−1 個交易日 WMA 尚未填滿視窗，輸出為空；RS-Ratio / RS-Momentum 需再疊第二層 WMA，實務上約需 **2L 個交易日** 才有穩定讀數。

---

## 第三步：RS-Ratio（橫軸 · 相對強度比率）

JdK 的橫軸**不是**「相對圖表起點 t₀ 漲了多少」，而是：**當前 RS 相對其自身 WMA 水準偏離多少**，再經第二層 WMA 平滑，最後 × 100。

```text
RS-Ratio(t) = WMA_L( RS(t) / RS_bar(t) ) × 100
```

| RS-Ratio | 意義 |
|----------|------|
| `= 100` | RS 貼近其自身 WMA——**相對強度均衡** |
| `> 100` | RS 高於自身 WMA——相對基準**偏強**（圖的右側） |
| `< 100` | RS 低於自身 WMA——相對基準**偏弱**（圖的左側） |

這裡的 100 是 **JdK 均衡基準**，不是「與基準指數同步」或「與圖表起點持平」。

### 運動學對應

```text
x(t) = RS-Ratio(t)
```

`x(t)` 是**相對強弱的位置**（雙層 WMA 平滑後的標準化水準）。

---

## 第四步：RS-Momentum（縱軸 · 相對強度動量）

橫軸只有「現在在哪」，還缺「正在往哪走」。JdK 縱軸是 **RS-Ratio 相對其自身 WMA 的比率**，同樣以 100 為均衡：

```text
RS-Momentum(t) = RS-Ratio(t) / WMA_L(RS-Ratio)_t × 100
```

| RS-Momentum | 意義 |
|-------------|------|
| `= 100` | RS-Ratio **貼近其 WMA**——動量中性 |
| `> 100` | RS-Ratio **高於其 WMA**——相對強度**正在改善** |
| `< 100` | RS-Ratio **低於其 WMA**——相對強度**正在惡化** |

### 微積分語言

連續時間下，可把 RS-Momentum 視為 RS-Ratio 的**平滑速度**：

```text
y(t) = RS-Momentum(t) ≈ dx/dt
```

RRG 的相平面是 **(x, dx/dt)**，不是 (x, d²x/dt²)：

- 縱軸是**速度**（一階導數），不是加速度
- 「加速度」留到二階：`d²x/dt² ≈ y(t) − y(t−Δt)`，用來解讀動量何時見頂/見底（研究層 `_feat()` 的軌跡特徵會用到）

> **與簡化教學版的差異**：部分入門文章用 `100 × x(t) / x(t−n)`（n 期 ROC）當動量；**本專案不用該公式**，請以 JdK 雙 WMA 為準。

## 第五步：平面運動——把標的想成一顆粒子

每個標的在 RRG 上是一條軌跡。時間 t 推進，粒子位置：

```text
P(t) = ( x(t), y(t) ) = ( RS-Ratio(t), RS-Momentum(t) )
```

圖心定在 **(100, 100)**。判斷象限時，永遠用**相對 100**，不是相對 0。  
本專案 `classify_quadrant()` 邊界：Momentum **`> 100`** 才算轉強側（`= 100` 歸轉弱/落後）。

```text
                    RS-Momentum (y)
                         ↑
              轉強       |       領先
           x≤100,y>100   |   x>100,y>100
                         |
        ─────────────────┼─────────────────→ RS-Ratio (x)
                       (100,100)
                         |
              落後       |       轉弱
           x≤100,y≤100   |   x>100,y≤100
                         |
```

| 象限 | 條件 | 運動學類比 | 白話 |
|------|------|------------|------|
| **Leading（領先）** | `x > 100` 且 `y > 100` | 在右側，速度向右 | 已偏強，且動量仍向上 |
| **Weakening（轉弱）** | `x > 100` 且 `y ≤ 100` | 在右側，速度向左 | 水準仍高，但動量已轉弱 |
| **Lagging（落後）** | `x ≤ 100` 且 `y ≤ 100` | 在左側，速度向左 | 偏弱，且仍在惡化 |
| **Improving（轉強）** | `x ≤ 100` 且 `y > 100` | 在左側，速度向右 | 仍偏弱，但已開始修復 |

這和高中物理「位移–速度」四象限判讀**同一套邏輯**，只是把：

- 位移 x → RS-Ratio（相對強度水準）
- 速度 dx/dt → RS-Momentum（相對強度變化率）

## 第六步：為什麼軌跡常呈「順時針」打圈？

典型輪動順序（**常見模式，不是物理定律**）：

```text
轉強 → 領先 → 轉弱 → 落後 → 轉強 → …
```

用運動學分段理解：

| 階段 | 發生什麼 | 相平面上的樣子 |
|------|----------|----------------|
| 轉強 → 領先 | x 從 ≤100 升向 >100，y 先維持 >100 | 從左上往右上拱 |
| 領先 → 轉弱 | x 仍在 >100，y 從 >100 跌破 100 | 從右上往右下彎 |
| 轉弱 → 落後 | y≤100 持續，x 開始跌破 100 | 從右下往左下移 |
| 落後 → 轉強 | x 仍在 ≤100，y 從 ≤100 升破 100 | 從左下往左上彎 |

關鍵直覺：**動量（y）通常比水準（x）更早轉折**——先看到「斜率變了」，之後才看到「位置跨過 100」。這個時間差讓軌跡容易形成環狀。

例外情況（正常，不是圖壞了）：

- 逆時針、來回抖動、貼著某象限不動
- 強趨勢標的可能長時間停在領先或落後
- 日頻象限會抖動；Regime 日報的 **tail** 為近 4 交易日軌跡，較適合讀短期輪動

## 手算小例子（L=2，基準固定 100）

> 專案實務用 **L=20**；這裡用 L=2 讓表格可手算追蹤。公式與 `rrg_rotation.py` **完全相同**。

標的收盤（基準恆為 100）：

| 週次 t | 標的價格 | RS(t) |
|--------|----------|-------|
| 0 | 100 | 1.000 |
| 1 | 103 | 1.030 |
| 2 | 108 | 1.080 |
| 3 | 110 | 1.100 |
| 4 | 108 | 1.080 |
| 5 | 104 | 1.040 |
| 6 | 100 | 1.000 |
| 7 | 98 | 0.980 |

**Step A — RS_bar = WMA_2(RS)**（t ≥ 1 才有值）：

| t | 計算 | RS_bar(t) |
|---|------|-----------|
| 2 | (1.030×1 + 1.080×2) / 3 | 1.063 |
| 3 | (1.080×1 + 1.100×2) / 3 | 1.093 |

**Step B — RS / RS_bar，再 WMA → RS-Ratio**：

- t=2：1.080/1.063 = 1.016；與 t=1 的 1.030/1.020 = 1.010 做 WMA_2 → 1.014×100 = **101.4**
- t=3：1.100/1.093 = 1.006；WMA_2 → **100.9**

**Step C — RS-Momentum**（t=3 起有值）：

- t=3：y = 100.9 / WMA_2(RS-Ratio) × 100 = 100.9/101.1×100 ≈ **99.9** → **轉弱**（x>100 且 y<100）

**讀圖摘要**（同一組價格，完整鏈由程式驗證）：

| t | RS-Ratio x | RS-Momentum y | 象限 |
|---|------------|---------------|------|
| 2 | 101.4 | — | （動量尚未填滿） |
| 3 | 100.9 | 99.9 | 轉弱 |
| 4 | 99.8 | 99.6 | 落後 |
| 7 | 99.1 | 100.1 | 轉強 |

把 (x, y) 依時間連起來，就是 RRG 上的一小段尾跡。若改為**連續探底再回升**的價格序列，會先見 **轉強** 再進 **領先**——與「落後 → 轉強 → 領先」敘事一致。

## 完整公式鏈（一頁總整理）

```text
標的收盤 P(t)、基準收盤 B(t)     ← 本專案 B = IX0001
         ↓
    RS(t) = P(t) / B(t)                    ← 相對位移（原始）
         ↓
 RS_bar(t) = WMA_L(RS)                     ← 第一層平滑
         ↓
 RS-Ratio = WMA_L(RS / RS_bar) × 100        ← 水準（橫軸 x）
         ↓
 RS-Momentum = RS-Ratio / WMA_L(RS-Ratio) × 100   ← 動量（縱軸 y）
         ↓
 平面軌跡 P(t) = (RS-Ratio, RS-Momentum)   ← 相對輪動圖
```

### 與微積分的對照

| 數學物件 | RRG 對應 | 白話 |
|----------|----------|------|
| f(t) = RS(t) | 原始相對強弱 | 走到哪 |
| WMA_L | 低通濾波 | 看大趨勢、去雜訊 |
| x(t) | RS-Ratio | 標準化後的位置（均衡 = 100） |
| dx/dt | RS-Momentum | 位置變化有多快 |
| (x, dx/dt) 相平面 | RRG 本身 | 一張圖同時看水準與斜率 |
| d²x/dt² | Momentum 的變化 | 動量何時見頂/見底（進階） |

## 怎麼讀一張 RRG 圖？

### 看單一標的

1. **尾跡終點在哪個象限？** → 現在的狀態
2. **最近幾個點往哪個方向移？** → 短期動量方向（Regime 日報 **tail** = 近 4 日）
3. **有沒有跨過 x=100 或 y=100？** → 水準或動量是否轉折
4. **尾跡長度與曲率** → 輪動快不快、是否穩定

### 看多標的（例如 ETF 成分股）

- 從**轉強**往**領先**移動的 → 可能正在成為下一波強勢（研究層 **fresh** 軌跡會進一步篩選）
- 停在**領先**但 y ≤ 100 → 強但動能衰竭（**轉弱**）
- 在**落後**但 y > 100 → 弱但開始修復（**轉強**）

RRG 的價值在於**同一張圖比較多個標的的相對運動**，不是只看絕對漲跌。

## 常見問題

### Q1：為什麼圖心是 100 不是 0？

JdK 慣例把**均衡狀態**對準 100：RS-Ratio = 100 表示 RS 貼近其 WMA；RS-Momentum = 100 表示 RS-Ratio 貼近其 WMA。這是**比率標準化**，不是 z-score（平均 = 0）。

### Q2：為什麼不用「相對圖表起點 t₀」來標準化？

那是另一種簡化教學寫法。本專案與 StockCharts / TradingView 開源 RRG clone 一致，採 **雙 WMA 比率**定義，軌跡才能與 `regime-daily`、研究報表、`compute_rrg_panel()` 輸出對齊。

### Q3：WMA20 可以換成 SMA20 嗎？

不建議在專案內自行替換：回測、日報、Lens 皆鎖定 `length=20` 的 WMA。若做研究 sweep，結果視為探索性，採納前需重新驗證。

### Q4：RS-Momentum 是加速度嗎？

不是。它是 RS-Ratio 相對其 WMA 的**一階變化率（速度）**。加速度要再看 Momentum 的變化（二階）。

### Q5：順時針一定會發生嗎？

不一定。順時針是**典型相對輪動**；強趨勢或盤整標的可能不會完整繞一圈。日頻象限亦可能高頻 flip（見 `quadrant_flip_rate()` 回測統計）。

### Q6：這跟因子研究有什麼關係？

本質相同：把某個因子值 x 和它的變化率 dx/dt 畫在一起。RRG 把時間順序接成軌跡，並用運動學語言（位置、速度、象限）解讀**相對基準**的橫截面輪動。

## 進階延伸（選讀）

### 極座標類比

以 (100, 100) 為原點：

- **徑向距離** r = √((x−100)² + (y−100)²)：偏離「均衡狀態」有多遠
- **角速度**：軌跡繞中心旋轉的快慢

適合已學極座標的讀者，用來理解「為什麼像在打圈」。

### 程式（與 `rrg_rotation.py` 一致）

```python
import numpy as np
import pandas as pd

def wma(series: pd.Series, length: int = 20) -> pd.Series:
    def _wma_window(x: np.ndarray) -> float:
        w = np.arange(1, len(x) + 1, dtype=float)
        return float(np.dot(x, w) / w.sum())
    return series.rolling(length, min_periods=length).apply(_wma_window, raw=True)

def rs_ratio_momentum(
    asset_close: pd.Series,
    bench_close: pd.Series,
    *,
    length: int = 20,
) -> tuple[pd.Series, pd.Series]:
    aligned = pd.concat({"asset": asset_close, "bench": bench_close}, axis=1).dropna()
    rs = aligned["asset"] / aligned["bench"]
    wma_rs = wma(rs, length)
    rs_ratio = wma(rs / wma_rs, length) * 100.0
    rs_momentum = rs_ratio / wma(rs_ratio, length) * 100.0
    return rs_ratio, rs_momentum
```

## 一句話記住 RRG

> **RRG = 把 RS 相對其 WMA 的強弱水準當位移、把 RS-Ratio 相對其 WMA 的變化當速度，畫在以 100 為均衡中心的相平面上，看各標的如何相對輪動。**
