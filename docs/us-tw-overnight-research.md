# US↔TW 隔夜研究總結（2026-08）

**研究問題**：能不能用美股隔夜（NQ/ES/VIX）＋鄰近亞洲市場，在台股開盤取得 edge？

**一句話結論**：US 隔夜 → 台股開盤是**11 年穩健的真關係，但它是公開、效率、不可套利的**。
唯一真實價值是**持現貨者的盤前跳空風控警示**（已建成 `morning_gate_brief`），
**不是**台指期夜盤的獲利策略——後者經回測證實無 alpha。

## 2. 台指期夜盤：正式回測證實「無 edge」

- **04:30（夜盤收前）**：正式 P&L 回測「08:45 進、13:45 出」→ 均 −0.002%/筆、**Sharpe −0.04**（效率）。
- **21:30（US 現貨開盤）**：23 年 SPY 決定性檢定「依隔夜方向追盤中」→ 均 −0.030%/筆、**Sharpe −0.52、24 年裡 18 年負**（隔夜後盤中微反轉，追＝站錯邊）。
- **乾淨 tick 交叉驗證**：corr(TX 夜盤, NQ 夜盤) = **0.73** → TX 即時跟 US、**無 lag** 可搶；剩 ~47% 是台股自身隔夜雜訊（無訊號可測）。

## 3. ⚠️ 資料修正教訓（本研究最重要的一課）

初版 13 天 tick 回測跑出 **Sharpe 6.30**，看似聖杯。經自我稽核發現是**壞資料**：
- **跨合約/換月**造成假報酬（配對跳到不同月合約）。
- **05:00 取到低量假 tick**（vol=2 的 print 當收盤價）。

修正（同一連續前月合約＋排除 spread＋量權 VWAP）後，那些 +4.4% 假大單**全部消失**，Sharpe 6.30 蒸發。
> **教訓：小樣本 + 高 Sharpe 幾乎都是陷阱（前視或壞資料）。必用長史 + 資料稽核殺掉。**
> 本研究先後殺掉兩個假 Sharpe：① `sign(US)×gap` Sharpe 7.5（前視）、tick Sharpe 6.30（壞資料）。
