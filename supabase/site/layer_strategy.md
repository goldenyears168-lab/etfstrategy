# 策略層

**策略層** 收錄 **已採納、凍結** 的規格。五軌 **並行**、**不加權合成**；回測摘要為證據。

| 項目 | 說明 |
|------|------|
| **角色** | 凍結規格 · 績效閱讀 · **每日篩選 brief** |
| **入口** | [策略目錄](strategy_catalog) → `/strategies` |
| **當日篩選** | Supabase `daily_briefs` · `brief_types` 對照五軌 registry |
| **統計證明** | 各策略 **採納報告** tab（sweep 大表 · 拒絕清單） |

## 建議閱讀順序

1. [策略目錄](strategy_catalog) — [五軌摘要](strategy_catalog#五軌一頁摘要) · [怎麼讀這張表](strategy_catalog#怎麼讀這張表)  
2. 策略頁 **凍結規格** — 例 [ETF00981A 跟單策略](strategy_00981a_l1h9)  
3. 同頁 **採納報告** — 為何凍結 L1H9 / C18acc / Pivot Gate（含 AUTO 大表）  

採納路徑：研究題目 → 檢定 → 凍結規格 →（可選）正式 screen brief。
