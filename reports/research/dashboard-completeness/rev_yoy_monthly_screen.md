# 月營收 YoY 動能 — 月選股產品化 (rev_yoy_monthly_screen)

把 Phase-4 驗證存活的橫斷面因子 **`rev_yoy_3m`(月營收 YoY 3 個月均動能)** 產品化成一支可跑的
「輸入日期 → 當月多空全截面名單」工具。**這是因子已驗證的多空全截面形態(空頭 Sharpe 仍 +0.72),
不是只做多綁 risk-on**;做多高營收動能、做空低營收動能/衰退。

- 腳本: `scripts/research/dashboard/rev_yoy_monthly_screen.py`
- 因子驗證來源(勿重述): `reports/research/dashboard-completeness/tej_fundamental_factor.md`(90 檔實跑、DSR 0.954、PIT 對抗式審查存活)
- 資料: `data/research/dashboard/tej_fundamental_{sale,industry}.parquet`(TEJ EWSALE + 產業標註)
- 當前名單快照 CSV: `reports/research/dashboard-completeness/rev_yoy_monthly_screen_current.csv`

## 2. 這支工具做什麼 / 與回測腳本的差別

`tej_fundamental_study.py` 是**回測**(全歷史 L/S 曲線、Sharpe、permutation、DSR);本腳本是**當下選股**——
給定 as-of 日期,對每檔取「公告日 `annd` ≤ as-of」的最新 3 筆月營收 YoY,取均、winsorize、橫斷面排序,吐出多空 decile。兩者共用同一份 PIT 乾淨資料與同一訊號定義,故名單與回測所驗證的因子**同源**。

| 步驟 | 做法 | 為何 |
|---|---|---|
| PIT gate | 只取 `annd ≤ as-of` 的營收列 | 台股月營收次月 10 日前公布(中位 37 日 lag),用公告日 gate 杜絕前視 |
| 訊號 | 最新 3 筆 YoY 均 = `rev_yoy_3m` | 驗證存活的形態(平滑動能,比單月穩;§7 逐年 IC 5/6 年正) |
| winsorize | 逐列 clip YoY 到 [−90, +300]% | 小基期轉正/併購/金控投資收益會噴到數千%,屬會計異常非動能 |
| 排序 | 橫斷面 percentile rank | 高動能做多、低動能做空(多空全截面,方向由 IS IC 固定) |
| 標註 | 併 `tej_fundamental_industry`(產業/名稱) | 供人工判讀產業 tilt(見 §4 保留) |

## 3. 使用說明

```bash
# as-of = 今天,多空各 decile
.venv/bin/python scripts/research/dashboard/rev_yoy_monthly_screen.py

# 指定日期(回看某月公告後的名單)
.venv/bin/python scripts/research/dashboard/rev_yoy_monthly_screen.py --asof 2026-07-31

# 改用 quintile(20%,回測所用邊界)、輸出完整排序 CSV
.venv/bin/python scripts/research/dashboard/rev_yoy_monthly_screen.py --decile 0.20 --csv out.csv
```

- **每月更新節奏**:台股每月 10 日前公告上月營收,故實務上**每月 10–15 日**跑一次即可拿到當月最新名單(本快照為 7/15 全數公告後)。
- `--decile 0.10`(預設)給較集中的 ~9 檔多空;回測驗證用的是 `0.20`(quintile),想對齊回測曝險改 `--decile 0.20`。
- winsorize 界寫死在腳本頂(`YOY_CLIP_LO/HI`),如要改為橫斷面百分位 winsorize 可在此調整。

## 4. 保留(不吹成聖杯,務必連同名單一起看)

沿用因子報告 §3/§7b/§8 已量化的限制——**產品化不改變這些保留**:

1. **中小型集中**:edge 幾乎全來自宇宙裡相對小型的一段(小型 tertile 全期 Sharpe +2.05 vs **大型 tertile +0.47、大型 IS 僅 +0.07**)。名單裡的**大型權值股(台積電級)訊號近乎無效**,應偏中小或全宇宙攤平看待,勿當大型股 alpha。
2. **單一多頭週期 OOS**:TEJ 財報資料 2021+,只有 ~1 個 IS + ~1 個偏多頭 OOS 循環;OOS>IS 的漂亮數字有殘留「集中單一多頭波段」風險(空頭 Sharpe +0.72 已大幅緩解,但未消除)。
3. **約半數為產業 tilt**:扣產業均值後 OOS Sharpe 從 +2.34 掉到 +1.22、perm_p 0.002→0.032。raw 名單約一半是「買到高成長產業(半導體/電子)」的 sector beta——當前多方 10 檔有 5 檔半導體即為此現象。純 within-sector 選股殘量仍顯著,但不能宣稱「產業中性後一樣強」。
4. **與 champion 非全正交**:corr +0.27(同吃部分多頭 beta),屬不同層(champion=L0 市場擇時、營收動能=L1 選股)分工,但非獨立疊加的免費 alpha。
5. **金融股訊噪比最低**:金控月營收受投資收益基期影響大(本期多方前段多金控、最新月與 3m 均常背離),winsorize 只能壓極值不能修基期,金融股入選應打折看待。
6. **已知因子非獨門**:revenue/earnings momentum(PEAD 族),價值在「台股真資料仍活」而非新發現。
7. **月營收 restatement vintage 無資料**:TEJ 月營收修正罕見且小,但無 vintage 表可證,屬殘存微小前視風險(§8.4 待補)。
