## 1. 這維度是什麼、專業為何看它

大盤融資維持率(斷頭風險溫度計)衡量散戶信用槓桿此刻「痛不痛」:

```
維持率 = Σ(所有融資部位現值) / 大盤融資金額(融資餘額) × 100%
```

三個常被混用的層級要先分清:

1. **單一部位維持率** = 擔保股票市值 / 融資金額。上市初始約 166%(借 6 成),跌至 **130% 追繳**、續跌斷頭。
2. **整戶擔保維持率**(證交所法規口徑,130% 追繳線的官方對象)=(融資擔保品市值+融券保證金+抵繳證券市值)/(融資金額+融券標的市值)。證交所 2026-07-27 澄清「全市場整戶擔保維持率約 175%」用此口徑加總。
3. **大盤融資維持率**(可回測因子最常用)= Σ融資股票現值 / 大盤融資餘額。媒體/工具(wantgoo、cmoney、istock、FinLab、TEJ)每日追蹤的那條線,常態帶 130–170%。

專業之所以看它:它是**散戶槓桿壓力的市場級溫度計**。逼近 130% 時,券商強制回補(斷頭)產生非線性、級聯的賣壓;極低水位往往出現在恐慌 flush 之後,對應空頭觸底反彈的 contrarian marker。**但它是「結果」不是「因」**——反映散戶當下的痛,而非預示未來,這決定了它的 lead/lag 定位(見第 5 節)。

## 2. 學術 / 業界 / GitHub 依據

- **TEJ TQuant「從融資維持率看穿轉折訊號」**(tejwin.com/insight,學界最常引用口徑):個股維持率 = 名目股價 /(每股融資成本 × 融資乘數),乘數上市 60% / 上櫃 50%。**因子化用相對異常偏低而非絕對值**:進場 = 當日維持率 < 過去 10 日 MA(即維持率跌幅),每日選跌幅最大前 10 檔,加三層濾網(紅 K 日、量趨穩、融資餘額未快速流出),停利 +40% / 停損 −10% / 最長 15 日。回測 2020–2025:年化 19.04% vs 大盤 18.39%、MDD −16.68% vs −28.47%、Sharpe 1.12 vs 1.04。**結論:反指標有效但邊際,主要贏在回撤控制,強調多層濾網。**
- **大盤融資維持率抄底分組回測(2009+)**(vocus.cc / 口袋學堂等在地 quant blog):跌破 150% 短線底、130–140% 高度恐慌、跌破 130% 近 120% 為斷頭後中長期底。宣稱斷頭區約 43 個交易日進場,往後 12 個月 0050 平均 +34.9% 且全數收正(≈隨機兩倍)。**但屬事後分組、事件叢集(2008/2015/2020/2022),樣本獨立性低,未過 OOS/Deflated 檢驗。**
- **證交所信用交易整戶擔保維持率澄清(2026-07-28,工商時報/數位時代引證交所)**:官方口徑含融資+融券+抵繳,全市場加權平均;2026-07-27 約 175% 遠高於 130% 追繳線——**確認「市場平均維持率被大部位主導、非個股恐慌代表」的方法論警告。**
- **GitHub**:`FinMind/FinMind`(含 `TaiwanTotalExchangeMarginMaintenance` 付費層維持率 + 免費層融資餘額原料,沿用本專案 `src/chip_data.py` 慣例);`mlouielu/twstock`、`toomore/grs`(補收盤價做分子 Σ張×close 的替代)。

## 3. 訊號精確定義、資料源、本地可得性

### 3.1 精確定義(正規化與方向)

- **不用絕對水位**(法規門檻/槓桿結構會隨年代漂移,150%/130% 是事後挑選)。用 **rolling 60/120 日 z-score 或 vs MA 的相對偏離**。
- **level 方向 = 順勢(momentum-collinear)**:維持率高≈籃子價格水位高≈上升趨勢(見第 4 節實測 IC 為正)。
- **contrarian 方向只在深尾**:維持率極低(flush 後)→ 均值回歸反彈——官方 ground-truth 實測**僅在最深 5% 尾部/絕對<150% 成立**(fwd20 lift +1.16%/+2.26%),p10 以上即洗掉;屬稀有事件標記,非系統化 z-score 訊號(見第 4 節)。
- **真正具前兆性的形態**(需個股層):「近斷頭部位廣度」=維持率 < ~140% 的融資市值佔比,作為強制賣壓級聯的前置條件(對齊本專案「融資新增廣度 / 分點賣超=事件前兆」格)。

## 4. 研究設計與實測結果(官方 ground-truth,已實跑 2018-06→2026-07,n=1985)

70/30 時間序 IS/OOS 分割(cut@1389;IS 2018-06-01..2024-02-05,OOS 2024-02-15..2026-07-29);次日 open→close 報酬;成本 4bps;permutation 3000 次 vs 同曝險隨機;方向由 IS IC 固定(+1)。

| 指標 | 值 | 解讀 |
|---|---|---|
| corr(MR_z60, 純價格動能_z60) | **+0.791** | **level 幾乎是價格動能的線性變換(核心陷阱在真資料上更明確)** |
| corr(MR_level, ix_close) | +0.492 | 水位隨大盤走 |
| IC_IS / IC_OOS(MR_z60→次日) | +0.017 / +0.043 | 正 IC=順勢,非 contrarian(MR_z120:+0.012/+0.051) |
| IC raw → 殘差化掉價格動能後 | +0.027 → **−0.012(縮水 57%,且翻負)** | **訊號扣掉價格動能後 IC 由正轉負——edge 就是價格動能本身** |
| IC 殘差化掉 margin_bal 後 | +0.012 | 相對融資餘額仍有微弱增量資訊(價格加權那一層),但極小 |
| long/flat OOS Sharpe | **+0.53**(B&H +0.39,champion +1.12) | 僅微幅勝 B&H,遠弱於 champion |
| OOS permutation p | **0.215(未過)** | **同曝險隨機打不贏——系統化訊號無顯著性** |
| regime:BULL / BEAR·盤整 Sharpe | +0.37 / +0.74 | 與 proxy 相反,無明確 bull-only 結構(小樣本雜訊) |
| **contrarian 深尾(MR_z60≤p05,97d)fwd20d lift** | **+1.16%**(fwd10 +0.52%) | **真資料下深尾反向成立**(proxy 為負,方向相反) |
| contrarian 尾部 p10/p20 fwd20 lift | +0.38% / −0.07% | 只在最深 5% 尾部有效,p10 以上洗掉 |
| **絕對水位 MR≤150%(90d)fwd20 lift** | **+2.26%** | **坊間「跌破 150 抄底」在真資料絕對水位上得到支持**(MR≤160 反而 −0.54%) |
| Deflated-Sharpe(OOS,~8 形態) | **DSR=0.258(未過 @0.95)** | obs annSR +0.53 < null 期望最大 +0.95;搜尋膨脹吃掉顯著性 |
| corr(MR_z60, champion=fut_foreign_oi_z60) | +0.079 | 與 champion 近乎正交(共線來自價格,非 champion) |

**結論(證偽優先)**:作為 level/z-score 系統化訊號,官方維持率是**被 normalize 過的價格動能**——corr 0.79、殘差化掉價格動能後 IC 由 +0.027 翻成 −0.012(縮水 57%)、OOS permutation p=0.215 未過、DSR=0.258 未過。其 OOS Sharpe +0.53 幾乎全是「多頭時維持率高」的順勢效果,弱於且對 champion 無增量(共線僅來自價格,與 champion 正交但更弱)。

**但坊間 contrarian 形態在真資料的深尾成立(proxy 誤判)**:MR_z60 最低 5%(97 天)後 20 日大盤平均 +1.16% lift;絕對水位跌破 150%(90 天,對應 2018/2020/2022/2025 flush)後 20 日 +2.26% lift。這是**真反向 marker**,但屬事件級、時間高度叢集、有效獨立事件僅個位數,系統化 permutation/DSR 幾乎必然吃掉顯著性——**是定性警示標,不是可加碼的 alpha**。原 proxy 尾部 lift 為負、與此相反,證明必須用 ground-truth 才能正確判斷此形態。

## 5. lead_lag 定位 + 層級 + 與 champion 的搭配

**定位:落後/同步為主、尾部帶前兆,明確非領先,方向 contrarian、強 regime 依賴。**

- **為何非領先**:維持率 ≡ 分子(現值,隨股價)/ 分母(慢變融資金額),分母日變動極小,故它幾乎就是「融資籃子價格水位」——與本專案既有分類「**融資餘額=落後(弱動能代理)**」同格,是融資餘額的價格加權孿生兄弟,資訊層級一致,**不會比外資期貨 positioning(champion,領先)更早**。官方 ground-truth 實測 corr 0.79、殘差化掉價格動能後 IC 由 +0.027 翻成 −0.012 直接證明。
- **唯一前兆形態**:個股層「近斷頭部位廣度」(維持率 <140% 融資市值佔比),是強制賣壓級聯的前置條件——放**前兆格**,與「融資新增廣度 / 分點賣超」同理。需全量個股維持率(見 scaffold `near_call_breadth`),且應對「forward flush 事件」而非次日報酬評估。市場層 ground-truth 無法回答此形態(單一加權線,無廣度分佈)。

**落點層級**:**L2**(籌碼核心之散戶槓桿壓力子項),受 **L0 regime** 閘控。系統化 z-score 形態實為 **L1 動能** 的冗餘代理(與價格動能共線),不獨立進 L2;唯有深尾/廣度形態才具 L2 獨立價值。

**與 champion(外資期貨 positioning,chip×bull OOS +1.79)的搭配**:

1. **不要當獨立 alpha 疊加**:corr(MR_z60, champion)=+0.079,雖與 champion 近乎正交,但它與**價格動能**共線(0.79)、殘差 IC 翻負、permutation/DSR 皆未過——加進 champion 只是疊一條較弱的順勢腿,無真正 alpha 分散。
2. **當「下行風險/情緒溫度計」互補**:champion 管 risk-on 進場,維持率的深尾(MR≤p05 / 絕對<150%,fwd20 lift +1.16%/+2.26%)管**斷頭壓力的定性反向警示**——當 champion 說多、但維持率殺進深尾時,提示「恐慌 flush 後的均值回歸窗口」,作為**過濾/擇時 confirm** 而非系統化進場訊號。
3. **regime 閘控**:深尾反向 marker 時間叢集於 2018/2020/2022/2025 flush,須配 L0 價格底部 confirm 使用;系統化 z-score 版在 BULL/BEAR 分層無穩定結構(+0.37/+0.74,小樣本雜訊),不宜單獨閘控。

## 6. 已知陷阱與規避

1. **與價格動能機械共線(最大陷阱)**:維持率是被 normalize 的價格動能,IC 與指數動能高度共線。**規避**:純水位訊號先對「同曝險價格動能」殘差化再看 IC(本研究已做:縮水 48%)。真正獨立資訊只在分母的槓桿累積/去化速度、與接近 130% 的非線性斷頭閾值效應。
2. **平均數被大部位拖動**:市值加權平均被少數大額/權值股融資主導,個股崩跌不必然拉低大盤數值(證交所 175% 澄清印證)。**規避**:用「廣度」(近斷頭部位佔比)而非平均水位當前兆。
3. **前視/資料延遲**:融資餘額盤後(T 日晚)公布,個股 T+1 可用;整戶維持率非每日欄位。**規避**:用 T 日收盤後才可得的維持率預測 T+1(本研究 day_ret 已 shift(-1))。
4. **樣本內過擬合**:150%/130% 閾值為事後挑選;斷頭區樣本高度時間叢集,permutation 與 DSR 幾乎必然吃掉顯著性。**規避**:用事件級(非日級)有效樣本數評估。
5. **regime 依賴**:訊號本質恐慌後均值回歸,空頭 flush 觸底才有效,盤整/緩跌破位常續跌。**規避**:必做多/空頭分層(本研究已做:BULL +0.55 / BEAR −0.02)。
6. **口徑漂移**:法規門檻、融資成數、當沖佔比、ETF/高股息熱潮改變融資結構,絕對水位不可跨期直接比較。**規避**:只用相對(z-score/vs MA)。
7. **覆蓋/回填偏誤**:市場層維持率**已用 FinMind 官方 ground-truth 序列**(整戶擔保維持率單一線,無 universe 抽樣問題),此偏誤在市場層已消除。**唯一殘留**:個股層近斷頭廣度仍受本地融資 universe 僅 ~176 檔(多數停在 07-07)限制——建該前兆形態前須先 data/replica 或 FinMind 全量回填。
